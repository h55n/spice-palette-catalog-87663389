# Spice Palette Catalog — Catalog UI

A responsive product-catalog interface built with React, TypeScript, Vite, Tailwind CSS, and component primitives. The project is a front-end design/prototyping exercise focused on product presentation and responsive browsing.

## Run locally

```bash
git clone https://github.com/h55n/spice-palette-catalog-87663389.git
cd spice-palette-catalog-87663389
npm install
npm run dev
```

Open the URL printed by Vite, normally `http://localhost:5173`.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui-style components

## Scope

This repository is a catalog/front-end prototype rather than a production commerce backend. Generated deployment-tool boilerplate has been removed from this README so the repository description reflects the project itself.
